# SkillSwap · 技能互换平台

> 用你会的，换你想学的。发布「我能教的 / 我想学的」，智能匹配互补伙伴，完成一对一技能交换。

## 在线演示

- 公开雏形：**https://c1861e23e307467c.flypod.page**
- 仓库：https://github.com/zixuanxiao-torch/AI-Test

## 解决什么问题

- 报班贵、自学难坚持
- 擅长的技能缺少分享与低成本变现/交换渠道
- 想学的人和能教的人难以相遇

## 产品功能

1. **创建主页**：昵称 / 城市 / 简介（本地浏览器存储）
2. **发布技能**：分别发布「我能教」「我想学」，含分类、水平、方式、时长、标签
3. **技能广场**：搜索、筛选、浏览演示用户与自建内容
4. **智能匹配**：按技能互补打分，优先双向互换
5. **互换消息**：发起 / 接受 / 拒绝 / 标记完成

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

更新公开演示（同一链接）：

```bash
npm run build
npx flypod update
```

## 技术说明

- Vite + React 单页应用
- 无后端：数据存 `localStorage`，内置演示用户便于面试官即开即用
- 静态托管，可公开长期访问（建议绑定稳定托管或登录 flypod 去掉试用期）
